Pendulum Simulator

One motion, three perspectives. Watch the pendulum move through its phase plane and time history.

θ″ + (μ / mL) θ′ + (g / L) sin θ = 0

Set the pendulum in motion

Angles are measured from vertically downward. Positive angles turn counterclockwise. Click the phase plane to set the initial angle and angular velocity.

The damping labels refer to the linearization near a downward equilibrium. Critical damping occurs when μ/(mL) = 2√(g/L).

t = 0.00 s

Phase plane

Horizontal: θ (rad), unwrapped. Vertical: θ′ (rad/s). Filled green dots: downward equilibria. Hollow red dots: upright equilibria. Blue: solution curve; orange: current state.
